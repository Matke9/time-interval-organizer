# Time Interval Organizer

A Focus Timer / Activity Timer PWA application that helps you organize your time into activities with segments, run countdown timers, and stay focused using a full-screen Focus Mode.

## Features

- Timestamp-based timers that survive tab sleep and page refresh
- Full-screen Focus Mode with activity grid
- PWA installable on mobile devices
- Dark theme with visual feedback
- Audio alerts on timer completion

## Getting Started

Open `index.html` in your browser or deploy to any static hosting service.
